原仓库：https://github.com/Andrew-li777/biolearn-practice

固定提交：`376d0f36ba33fd7e0db3091c247ee259247c04f4`。科学运行日期为 2026-10-30，结果解读日期为 2026-10-31；网站构建日期将单独生成。

| 内容 | 状态 | 第一版支持 | 不支持的推断或功能 |
|---|---|---|---|
| 四项目统计摘要 | 已公开 | 数量比较、筛选、排序、下载 | 不能当作完整基因结果表 |

| 结果解读报告及证据索引 | 已公开 | 正逆向追溯、两例案例及逐样本摘录 | 案例不是完整蛋白检索库 |

| Ubi1/Ubi6 火山图、完整蛋白差异表 | 未公开 | 对比统计与公开案例 | 处理组切换不应偷偷复用 Ubi4 图片 |

显著数、阈值与效应方向不可由 UI 独立硬编码。摘要 rows 是字符串数组，需要严格映射为类型化数值。样本数、ARI/NMI、Jaccard 等部分数据目前位于公开文案或报告，不是摘要独立字段：整理成结构化元数据并保存章节/表格出处，禁止暗示统一从字段直接读取。

来源映射中的原始 results 路径即使有摘要记录的哈希，也不表示文件已公开。只有固定提交中真实存在的文件才可生成 GitHub blob 链接。区分公开内容、已公开摘录、未公开源产物。下载仅针对实际打包内容。

实施时创建白名单同步脚本，从 git show 固定提交读取文件、验证图片 SHA-256、输出目录内快照及内容清单；不得递归复制原项目。普通构建不读取父目录、不联网拉取最新 main。更新数据需要显式同步并审阅差异。

所有重要结论关联项目、来源提交、文件与字段/章节、比较、阈值、科学验证日期和证据状态。报告声称的历史回读不能在网页上改写为本次浏览实时核验。
