# 页面与交互设计

## 视觉系统

产品名：BioLearn | Bioinformatics Analysis Explorer。中文主文案＋英文术语；深色默认，支持浅色。桌面左侧导航＋顶部来源栏＋主内容，移动端改为带焦点管理的导航抽屉。

深色底 #0B1220、面板 #111D2E，青蓝 #38BDF8 用于主要操作，青绿 #2DD4BF 表示可用状态，紫色 #A78BFA 用于辅助比较；浅色以 #F5F8FC 与白色面板为主。颜色不能成为唯一状态编码，最终对比度以测试为准。正文优先系统中文字体，代码使用系统等宽字体，不依赖外部字体请求。

使用留白、细边框、清楚的标题层级，图表而非装饰图作为视觉主体。卡片有不同内容结构，不做八页重复模板。无装饰性 DNA、假动态指标或无意义进度条。科研图不反色、不裁去坐标和图例；浅底图保留独立图框。动画约 120–180ms，尊重 reduced-motion。

## 八个页面

| 页面 | 内容与专属交互 |
|---|---|
| Overview | 项目介绍、4 张独立路线卡片、技术栈、可点击流程地图、来源与日期、真实图像预览；不能把不同单位指标相加 |
| Bulk RNA-seq | airway 配对设计、矩阵起点流程、方法选择、3 方法 FDR<0.1 数量比较、过滤/模型差异、PCA 和 DESeq2 火山图；选择 edgeR 时不把 DESeq2 图片改标题冒充 |
| Single-cell RNA-seq | QC 前后对照、两路线标签及并排 UMAP、簇数与 ARI/NMI、marker 支持的推定注释与诊断边界；不直接比较 UMAP 坐标 |
| RNA-seq Workflow | 标为结构示意的流程图、Nextflow/nf-core 版本、历史任务与验收、命令和证据；不冒充实际任务 DAG、实时运行或 airway 原始数据复现 |
| Proteomics | LFQ 预处理、VSN/MinProb/limma、组别选择、FDR 与双阈值数量图、PCA、Ubi4 火山图/热图、共同可检验集合 Jaccard、两个案例 |
| Methods & Reproducibility | 按项目浏览输入输出、方法、参数、软件环境、版本锁、命令复制、验收范围、公开源码 |
| Evidence Explorer | 正序/倒序切换，项目/阶段/状态筛选，关键字检索；结论抽屉内展示发现、方法、阈值、来源、支持范围、反例与限制 |
| About & GitHub | 定位、阅读路线、来源仓库与未来前端仓库入口、验证边界；未配置前端远端时不伪造 URL |

## 通用交互与空状态

- 主题持久化到 localStorage，存储不可用时仍正常工作。
- 表格排序保留原始数值精度；显示四舍五入不改变计算。下载 CSV/JSON 标注其摘要或摘录范围。
- 图像查看器提供适屏、缩放、复位、下载、来源及全屏；浏览器不支持 Fullscreen API 时仍可使用放大模态框。
- 键盘导航、Escape 关闭、焦点返回触发元素；图标按钮有可访问名称。图表同时提供文本摘要与表格。
- 搜索范围明确为公开摘要/方法/案例。空结果说明可搜索范围，不宣称存在全基因库。
- 切换 Ubi1/Ubi6 时更新真实摘要和可用案例；对应火山图/热图显示未公开，不复用 Ubi4 冒充。静态图无假悬停点数据。
- 证据链四项目各自独立，当前模式用流程节点和详情联动，不使用假 AI 对话功能。
- PIK3C2B 案例明确六个观测没有直接插补、效应相同而显著性不同；不直接归因于自身缺失值填补。RPS27A 案例不包装成关键调控因子。

## 未来数据条件

完整差异表公开并经核验后才增加基因/蛋白全表检索与动态火山图；真实逐细胞坐标和标签公开后才增加点选 UMAP；marker 表达还需表达矩阵及尺度说明。预留能力标识，不能通过模拟数据实现视觉替身。
