## 信息结构与保留映射

导航保留 Overview、四项目、Methods、Evidence 和 About 共 8 个入口；不删除已公开功能。总览从营销型 hero 改为项目索引；四项目分别改为阶段工作区；方法文件搜索和状态筛选保留在 Methods，证据页保留项目/状态筛选与搜索。证据案例的正逆向切换将内容本身重排，不只是更改按钮标签。主题、方法选择、表格排序/筛选/下载、摘要柱状图、原图查看/缩放/全屏/下载及固定来源链接均保留。

阅读路径示例：Proteomics → 差异富集 → 查看 FDR 与效应阈值表及 Ubi4 图 → 敏感性 → PIK3C2B → 对照主/不插补统计及六个样本 → 来源报告与限制。切换 Ubi1 或 Ubi6 时不显示 Ubi4 图。Bulk 选择 edgeR/PyDESeq2 时隐藏仅属于 DESeq2 的火山图。

## 真实数据与结果限制

四项目独立，网站不构造多组学机制链。`src/sample-values.json` 和 `src/case-metrics.json` 从公开报告摘取，并通过 `scripts/extract-cases.mjs --check` 和单元测试逐值对照已公开报告；不是完整蛋白结果表。每阶段链接固定提交的方法文档和相关脚本；自动检查 19 个路径在该提交真实存在。结果表仍来自原 portal.json，不修改 public 数据或科研图片。

完整差异表、逐细胞数据、Ubi1/Ubi6 火山图及完整 MultiQC 未公开，因此没有动态火山点、全基因搜索、细胞点选或这些图的伪造替代。新增敏感性结果不等于独立生物学验证。浏览器图例中 protein 火山图为 BH FDR，bulk DESeq2 图的纵轴为原始 p 值变换、颜色为 FDR；页面分开说明。
